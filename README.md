# Мастер Кандзи N5

Справочник по 80 кандзи с русскими и узбекскими переводами и тестами на чтение и значение.

В карточках 619 слов и выражений, от 6 до 9 на каждый кандзи. Сначала идут базовые значения и чтения, затем употребительные сочетания. Для чисел отдельно показаны даты, время и длительность. Некоторые дополнительные слова выходят за рамки начального уровня.

Фуригана ставится только над кандзи. Хирагана, катакана, приставки и окончания остаются в основном тексте. Нерегулярные чтения, например 今日 и 大人, подписываются целиком. Точка в списке кунъёми отделяет окончание слова и не произносится.

## Возможности

- **Прежний Дизайн**: сохранены исходные цвета, шрифты, вертикальная компоновка и оформление карточек. Поиска нет, все 80 кандзи доступны в сетке справочника.
- **Размеры и Читаемость**: на экранах от 1024 пикселей рабочая область расширена до 640 пикселей, базовый размер текста увеличен до 18 пикселей. На смартфоне используются ширина и доступная высота экрана. Увеличены подписи и зоны нажатия, уменьшены интервалы между буквами, добавлены переносы длинного текста и отступы для экранных вырезов. На коротких экранах содержимое прокручивается без сжатия кнопок.
- **Подписи и Заголовки**: в интерфейсе используется Title Case, например "Выберите Ответ Клавишами" и "Слова и Выражения". Предлоги, союзы и частицы внутри фразы остаются строчными: "Работа над Ошибками", "Результат не Сохранится". Переводы, примеры и грамматические пояснения сохраняют обычный регистр.
- **Карточки с Начала**: при каждом открытии карточка показывается сверху. Предыдущее положение прокрутки не сохраняется.
- **Пять Секунд на Чтение**: после ответа кнопка следующего вопроса становится доступна через 5 секунд. Автоматического перехода нет: ученик может читать столько, сколько нужно.
- **Управление с Клавиатуры**: A, B, C, D или 1, 2, 3, 4 выбирают ответ, Enter открывает следующий вопрос после задержки. Escape закрывает карточку справочника. Tab переключает элементы внутри открытой карточки.
- **Работа над Ошибками**: в результатах можно нажать на ошибку и открыть соответствующую карточку.
- **Сохранение Настроек**: язык, режим теста и количество вопросов сохраняются в браузере. Прогресс теста и прокрутка карточек не сохраняются. Если браузер запрещает хранение настроек, приложение продолжает работать.

Для исходных шрифтов используются Google Fonts, для значков Font Awesome. Сам справочник и тесты работают без серверной части. Карточки появляются с короткой анимацией. Эффект заголовка срабатывает при наведении; настройка уменьшения движения отключает анимации.

## Обновление GitHub Pages

Распакуйте архив и замените в корне репозитория три файла: `index.html`, `styles.css` и `script.js`. `README.md` и папку `tests` также можно загрузить, они содержат описание и проверки. Сохраните изменения в ветке, из которой публикуется GitHub Pages. Дополнительная сборка не нужна.

После завершения публикации обновите страницу без кэша, если браузер показывает старую версию.

## Запуск

Сайт состоит из статических файлов. Для локального просмотра можно запустить сервер из корня проекта:

```sh
python3 -m http.server 8000
```

После запуска откройте http://localhost:8000.

## Проверка

Для проверок нужен Node.js 18 или новее. Дополнительные пакеты не требуются.

```sh
node --check script.js
node --test tests/*.test.cjs
```

Проверяются полнота данных, разметка фуриганы, сохранность японских предложений, отсутствие повторяющихся записей внутри карточек, генерация вопросов в обоих языках и всех режимах, пятисекундная задержка, сброс прокрутки карточек и вопросов, клавиатурное управление и сохранение настроек.

Проверки взаимодействия используют имитацию браузерных объектов. Они проверяют логику, но не заменяют визуальную проверку в браузере. Для ручной проверки рекомендуются ширины 320, 390, 768 и 1440 пикселей, горизонтальная ориентация телефона и увеличение масштаба до 200%. Откройте длинную карточку, прокрутите её, закройте и снова откройте: сверху должен быть виден кандзи. В тесте до истечения пяти секунд переход недоступен, затем карточка ждёт нажатия.
